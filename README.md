An entry for the [make.fun](https://make.fun/c/u-kiencx-sorry-i-heard-that-wrong-1858c729)
bounty "Sorry, I Heard That Wrong" — write the funniest one-line apology
a smart speaker gives its owner after mishearing them, at most 140
characters.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> Sorry, I heard 'set a timer for ten minutes' as 'set fire to the kitchen.' The fire department has been notified.

113 characters, one line — the speaker misheard a harmless kitchen timer
as an instruction to set fire to the kitchen, then reports the fire
department's arrival in the same flat, helpful voice it uses for a timer
confirmation. The apology is sincere, the consequence is a house fire,
and the device sees no contradiction — that gap is the laugh. No
misheard song title, no misheard name: a fresh mishearing with a
perfectly timed undercut.
